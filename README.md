# Doom Emacs в браузере

Статическая страница для GitHub Pages. Unkernel запускает Alpine Linux и показывает вывод загрузочной консоли. Кнопка **Открыть Doom Emacs** запускает редактор внутри этой виртуальной машины и открывает `~/notes.org`. В образ включена конфигурация Doom с темой Doom One и клавишами Evil. Файлы и конфигурация сохраняются на диске виртуальной машины в браузере.

## Открыть на iPad

1. Откройте ссылку GitHub Pages в Safari на iPadOS 27 или новее. Unkernel использует WebAssembly JSPI. [Поддерживаемые браузеры](https://github.com/pithings/unkernel/tree/v0.2.0-261123-8f039c5#-try-it-in-the-browser)
2. Дождитесь загрузки Alpine и нажмите **Открыть Doom Emacs**. Коснитесь **Клавиатура** или подключите физическую клавиатуру. Для ввода нажмите `i` или **Вставка (i)**. `Esc` возвращает в обычный режим Evil.
3. Нажмите **Сохранить** или `Ctrl+X`, затем `Ctrl+S`. Дождитесь сообщения о сохранении. **Скачать notes.org** выгружает сохранённую версию в «Файлы». **Вставить файл** вставляет текст из UTF-8-файла в текущую позицию курсора.

Используйте ту же ссылку и тот же профиль Safari для доступа к сохранённым файлам. Для переноса на другой iPad или компьютер скачайте заметку. При очистке данных сайта Safari удаляет хранилище страницы.

## Управлять Alpine

- **Терминал Alpine** открывает Bash от пользователя `user`. Используйте `sudo` для прав root. Doom доступен через команду `doom`, пользовательская конфигурация лежит в `~/.config/doom/`.
- Переключайтесь между **Doom Emacs**, **Терминал Alpine** и **Загрузка**. Редактор и оболочка продолжают работать, пока открыт другой вид. **Диагностика** показывает вывод команд, включая PID Emacs.
- **Перезагрузить ВМ** завершает сеансы и повторно загружает Alpine с сохранённым диском. Для выключения из оболочки выполните `sudo poweroff`.
- По умолчанию у гостевой системы нет сети. Для `apk add` и обновления пакетов Doom откройте страницу с параметром `?wisp=wss%3A%2F%2Fproxy.example.org%2Fwisp%2F`, подставив адрес своего Wisp-прокси, который принимает подключения с домена сайта.

## Развернуть на GitHub Pages

1. Загрузите исходники из этой папки в ветку `main` репозитория на GitHub. Папка `dist/` собирается в CI.
2. В репозитории выберите **Settings → Pages → Build and deployment → Source → GitHub Actions**.
3. Откройте **Actions → Deploy Emacs to GitHub Pages → Run workflow** и выберите `main`. Следующие изменения в `main` публикуются автоматически.
4. Откройте адрес из завершившегося задания `deploy` на iPad. Для обычного репозитория это `https://<владелец>.github.io/<репозиторий>/`.

[Документация GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages)

## Локальная сборка

Нужны Node.js 26 и доступ к GitHub, npm и зеркалу Alpine Linux. Сборка устанавливает `emacs-nox`, закреплённую ревизию Doom и пакеты активных модулей в образ Alpine и проверяет запуск из готового образа.

```sh
npm ci --ignore-scripts
npm run build
npm run preview
```

Откройте [локальный адрес](http://127.0.0.1:4173/unkernel-emacs/) в браузере с JSPI. Путь `unkernel-emacs/` имитирует публикацию проекта в подпапке GitHub Pages.

После изменения интерфейса `npm run build:ui` обновляет статические файлы в `dist/` с уже собранным образом Alpine.

## Локальный тест Wayland и WebGPU

Соберите обычный образ Doom, затем соберите графический образ и запустите локальный сервер.

```sh
npm run build
npm run build:graphics
npm run preview
```

Откройте [графический режим](http://127.0.0.1:4173/unkernel-emacs/local-graphics/) в Chrome или Edge с JSPI и WebGPU. **Открыть Doom Emacs** запускает окно Wayland. **Запустить vkcube** проверяет гостевой Vulkan через WebGPU. В диагностике поддерживаемого браузера будет `kwvk (WebGPU)`.

Графический режим использует отдельный Debian и временный диск. Заметки в нём живут до выключения ВМ или обновления страницы. Сборка GitHub Pages не запускает `build:graphics`.
